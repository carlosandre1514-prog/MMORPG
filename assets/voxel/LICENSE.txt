O QUE ISSO EXIGE
- Atribuição obrigatória ao autor (monogon / Max Parata): consta no README e na janela de Ajuda do jogo.
- ND (sem derivações): não se pode distribuir uma versão MODIFICADA do material. O voxel.glb deste diretório é uma versão
  convertida (cores gravadas nos vértices, base no chão, escala e uma versão @lod simplificada de cada prédio), gerada por
  tools/voxel/convert.mjs. Segundo um comentário informal do autor, jogos podem usar os prédios, mas os arquivos em si não podem ser
  redistribuídos, mesmo modificados.
- ANTES DE PUBLICAR o jogo para outras pessoas: peça autorização por escrito ao autor (itch.io) para incluir esta versão convertida,
  ou troque os prédios por outro pacote livre. Para testes privados não há problema.
